# 工作流程

1. 先确认题目的输入、输出、数据范围和边界情况。
2. 选择正确算法，控制时间与空间复杂度。
3. 生成符合题目提交格式的 C++17 代码。
4. 使用本地编译器检查语法，并运行至少一个有代表性的测试样例。
5. 最终回答说明算法、复杂度、测试结果和修改文件。
